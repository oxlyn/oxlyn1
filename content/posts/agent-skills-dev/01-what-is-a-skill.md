> 本文对应官方标准[《Agent Skills Overview》](https://agentskills.io)与 [Claude Code 技能文档](https://code.claude.com/docs/en/skills)。

**学习目标**：理解技能解决什么问题、一个技能由什么组成、渐进披露如何省上下文，以及技能与[MCP](/posts/mcp-dev/)等机制的分工。

你一定有这类经验：每次让 AI 做某件固定的事（写周报、按团队规范建组件、提交代码），都要把同样的要求重新讲一遍——粘进对话、写进系统提示、或抄进项目的说明文件。这些"**每次都要重复交付的知识**"，就是 Agent Skills 要装进文件夹的东西。

> 内容依据 [agentskills.io 开放标准](https://agentskills.io)（Anthropic 发起，2026 年已有数十家工具支持）与 [Claude Code 文档](https://code.claude.com/docs/en/skills)整理，代码示例均为原创，每章附官方文档链接。

## 技能：一个文件夹的承诺

技能的定义朴素到令人意外——**一个包含 SKILL.md 的文件夹**：

```text
commit-helper/
├── SKILL.md          # 必需：元数据 + 指令
├── scripts/          # 可选：可执行脚本
├── references/       # 可选：参考文档
└── assets/           # 可选：模板与样板
```

SKILL.md 由两部分组成：YAML frontmatter（`name`、`description` 是最低要求）+ Markdown 正文（给 AI 的指令）。就这么简单——没有 SDK、没有注册 API，**知识变成了可版本管理、可分享、可移植的文件**，像 README.md 之于仓库。

关键在可移植性：SKILL.md 是**开放标准**，同一个文件夹在 Claude Code、Codex、Gemini CLI、Cursor、VS Code、OpenCode 等工具里都能用——写一次，你的所有 AI 助手都会。

## 渐进披露：为什么技能不撑爆上下文

装几十个技能，上下文却不爆炸，靠的是三段式加载：

| 阶段 | 进上下文的东西 | 时机 |
| --- | --- | --- |
| **发现** | 每个技能的 name + description（几十 token） | 会话启动时全部就位 |
| **激活** | SKILL.md 正文全文 | 任务匹配到描述时 |
| **执行** | 引用的文件、执行的脚本 | 指令用到才读 |

类比：**description 是书脊上的书名，正文是书的内容，references/ 是附录**——你不会为了找一本书而背下图书馆的所有藏书。这个设计让"技能库"可以长到很大，而每轮对话的固定开销保持很小。

## 与其他机制的分工

Agent 可扩展的"记忆与能力"机制不止一种，选对才不内耗：

| 机制 | 装什么 | 类比 |
| --- | --- | --- |
| 系统提示 / CLAUDE.md | 项目级恒定约定（少而精） | 宪法 |
| **Skills** | 过程性知识：按需触发的任务流程 | 操作手册 |
| [MCP](/posts/mcp-dev/01-protocol-and-architecture/) | 外部工具与数据的**连接** | USB-C 接口 |
| 子代理 | 隔离上下文的并行任务 | 外包团队 |

判断口诀：**每次会话都需要 → 系统提示；特定任务才需要 → 技能；要连接外部系统 → MCP；既定流程+外部系统两者都要 → 技能编排 MCP**。官方把技能定位成"指令与流程的轻量方案"，MCP 定位成"工具与数据的连接方案"——两者组合而非互斥（[MCP 系列第 10 章](/posts/mcp-dev/10-ecosystem/)的生态观在这里接续）。

## 技能的四种典型用途

- **流程固化**：发版步骤、事故响应、代码评审清单——多步操作变成一致可审计的程序；
- **风格注入**：团队的命名约定、文档格式、[本站的文章规范](https://oxlyn1.pages.dev/about/)——AI 产出直接符合标准；
- **领域知识**：某个老系统的架构说明、某接口的坑位清单——装进技能，随叫随到；
- **工具组合**：把"调这几个脚本、按这个顺序"封装成一步——为确定性任务写代码（第 6 章）。

## 踩坑提示

- 把技能当"更大的系统提示"——什么都往里塞，触发就淹没模型；技能装**任务**，不装背景；
- 以为技能能连数据库——连接外部系统是 MCP 的活，技能只是"指挥 MCP 的乐谱"；
- 把 SKILL.md 写成千行大而全——渐进披露的收益就没了，第 5 章教你拆；
- 复制粘贴旧提示词当技能——先按"任务"重写成祈使句指令，粒度对了技能才灵。
